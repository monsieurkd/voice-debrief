# Digital Sanctuary Style Guide

## Philosophy: Cognitive Calm
The Digital Sanctuary is designed to prioritize human thought over machine efficiency. It employs "Intentional Friction" and a "Neo-Aerostat" aesthetic to shift the user from a task-oriented operator to a reflective thinker.

## Visual Identity
- **Primary Aesthetic:** Neo-Aerostat / Cloud-Modern.
- **Atmospheric Light:** Ambient Alice Blue emanating from the center of the workspace using radial gradients.
- **Structural Depth:** Components use "tectonic" shadows (large-radius, low-spread) and 32px corner radii to feel like they are floating in a void of focus.
- **Glassmorphism:** High-blur backdrop effects on navigation elements (SideNavBar) to allow ambient light to bleed through.

## Typography
- **App Title & Headers:** `Playwrite Deutschland Grundschrift`. A script-like face that adds personal character and a sense of "handwritten" reflection.
- **Body & UI Text:** `Open Sans`. High legibility, neutral, and modern to balance the script headers.
- **Hierarchy:** Strong contrast between script headers and clean sans-serif body text to establish clear information architecture.

## Color Palette
- **Surface:** #F7F9FF (Ethereal Alice Blue)
- **Primary:** #5C7CFA (Intellectual Blue)
- **Background:** Soft radial gradients of Alice Blue to white.
- **Accents:** Low-opacity lavender and soft blues for micro-interactions.

## UI Patterns
- **Ambient Conversation:** Thoughts exist on a shared plane without traditional chat bubbles.
- **Generative UI:** The interface morphs based on data type (e.g., ghost rows in tables, fluid transitions).
- **Floating Containers:** Replacing hard borders with soft shadows to reduce ocular and cognitive fatigue.
